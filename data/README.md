# Dataset

This project uses the IEEE-CIS Fraud Detection transaction dataset.

The dataset was used for:
- Data understanding and exploratory analysis
- Descriptive statistical analysis
- Transaction amount distribution analysis
- Outlier detection using IQR and Z-score methods
- Fraud pattern analysis
- Time-of-day and product-category analysis
- Hypothesis testing
- Statistical fraud-signal identification
- Business recommendations

## Dataset Availability

The raw dataset is intentionally not included in this GitHub repository because the source file is approximately 652 MB and is not suitable for direct repository storage.

The analysis notebook expects the dataset to be available locally.

## Dataset Selection

The internship task allowed the use of UPI fraud, credit-card fraud, digital-payment, or synthetic transaction datasets. This project uses the IEEE-CIS Fraud Detection dataset, representing card-not-present/payment fraud data, to demonstrate the required statistical fraud-analysis methodology.
